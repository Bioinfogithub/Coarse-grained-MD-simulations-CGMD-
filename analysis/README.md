# CGMD Analysis

Analysis is organized into:

- `rmsd/` — structural deviation
- `rmsf/` — residue/bead fluctuations
- `rg/` — radius of gyration
- `sasa/` — solvent-accessible surface area

For Martini protein systems, RMSD/RMSF analysis should normally use an explicitly defined CG backbone (`BB`) group. citeturn3view1
