# Martini 3 Force-Field Files

Place the exact Martini 3 force-field files required by the simulation here.

Typical files include:

```text
martini_v3.0.0.itp
martini_v3.0.0_solvents_v1.itp
martini_v3.0.0_ions_v1.itp
```

Use the official Martini 3 distribution/version appropriate for the simulation. Do not mix force-field versions without checking compatibility.
